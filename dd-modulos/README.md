### Formato de Cada Módulo

Cada módulo é documentado com:

| Campo | Descrição |
|-------|-----------|
| Nome Técnico | Identificador único (ex: `sale_management`) |
| Nome Amigável | Nome para exibição (ex: "Vendas") |
| Autor | Desenvolvedor do módulo |
| Versão | Versão instalada |
| Repositório | URL do código fonte |
| Descrição | O que o módulo faz |
| Dependências | Módulos dos quais depende |
| Configuração | Menus e parâmetros disponíveis |
