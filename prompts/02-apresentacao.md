# Prompt: Gerar Apresentacao para Cliente

## Objetivo

Gerar apresentacao HTML para clientes demonstrando o sistema Odoo 16 e suas funcionalidades.

## Template de Referencia

Usar como base: `templates/apresentacao.html`

## Instrucoes

### 1. Estrutura da Apresentacao

A apresentacao deve conter:

```html
<!-- HERO -->
- Titulo principal
- Subtitulo descritivo
- Badge com nome do cliente

<!-- VISAO GERAL -->
- Estatisticas do projeto
- Metricas importantes

<!-- FUNCIONALIDADES -->
- Grid de cards com icones
- Descricao de cada funcionalidade

<!-- MUDANCAS -->
- Comparativo Antes/Depois
- Beneficios da migracao

<!-- CRONOGRAMA -->
- Timeline de implementacao
- Fases do projeto

<!-- CTA -->
- Chamada para acao
- Botao de contato
```

### 2. Regras de Design

- Usar paleta de cores: `#714B67` (primary), `#9C6B8E` (accent)
- Cards com sombra e bordas arredondadas
- Icones em circulos coloridos
- Gradiente no hero e no CTA
- Responsivo para mobile
- Fonte: Segoe UI / system-ui

### 3. Conteudo Obrigatorio

Cada apresentacao DEVE conter:
- [ ] Hero com titulo e badge do cliente
- [ ] Pelo menos 4 estatisticas
- [ ] Pelo menos 3 funcionalidades em cards
- [ ] Comparativo v14 vs v16
- [ ] Timeline com pelo menos 3 fases
- [ ] CTA com botao

### 4. Tom de Voz

- Profissional mas acessivel
- Focado em beneficios para o cliente
- Evitar jargao tecnico excessivo
- Destacar ganhos de produtividade
- Portugues do Brasil

### 5. Exemplo de Uso

**Entrada:**
- Cliente: Empresa XYZ
- Projeto: Migracao Odoo 14 para 16
- Modulos: Vendas, Compras, Estoque

**Saida:**
- Arquivo: `apresentacao-xyz.html`
- Conteudo: Apresentacao completa seguindo o template

### 6. Checklist de Qualidade

- [ ] Template HTML seguido corretamente
- [ ] Cores da paleta aplicadas
- [ ] Conteudo focado no cliente
- [ ] Estatisticas relevantes
- [ ] Funcionalidades claras
- [ ] Cronograma realista
- [ ] CTA persuasivo
- [ ] Responsivo
