## Breaking Changes

### v17
- **MUDANÇA CRÍTICA**: Migração completa para OWL (Odoo Web Library)
- Substituição do jQuery por OWL
- Atualização de todos os templates XML
- Mudança na estrutura de componentes

### v18
- Alterações na API de domínio
- Atualização dos métodos de busca

## Notas

- Módulo core fundamental para toda a plataforma
- A migração v16 → v17 é a mais crítica devido à mudança para OWL
- Recomenda-se testes extensivos antes de migração
- Verificar compatibilidade com módulos customizados
